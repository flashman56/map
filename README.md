# 青岚市地铁建设沙盒（2D 俯视版）

在浏览器中运行的 **2D 俯视** 地铁自由建造沙盒。架空城市「青岚市」含机场、高铁站、CBD、住宅/工业区、大学、体育场、医院、港区与公园；无胜负条件，可自由规划线路、设站、选择工法，并观察简化客流。

> **视角变更**：已放弃 Three.js 3D 轨道场景，主界面为 Canvas2D 城市示意图（地铁图式 / 软插画风）。

## 如何运行

纯静态页面，**无需 npm / 无 CDN 依赖**。

```bash
python3 -m http.server 8080
```

浏览器打开 http://127.0.0.1:8080/  
（请用本地 HTTP，勿用 `file://`，否则 ES Module 可能无法加载。）

## 城市图层（怎么画出来的）

| 层 | 说明 |
|----|------|
| 地形底色 | `bakeCityBase()` 按地质采样（平原/软土/硬岩/水系/山地）预烘焙离屏图 |
| 分区晕染 | `DISTRICTS`：空港、高铁站、CBD、住宅、工业、大学、体育场、医院、港区、公园 |
| 中文标注 | 底图上设施图标 + 中文名 |
| 路网层 | 运行时绘制：轨道、节点、站点、幽灵预览、列车 |
| 客流反馈 | 拥堵色、站点 +客运、小地图视口框 |

世界坐标仍用 `x/z`（与旧存档兼容）；屏幕映射由 `cam {x,z,zoom}` 完成。

## 操作概要

| 操作 | 说明 |
|------|------|
| 左键拖拽 | 浏览模式：平移；铺轨模式：拖拽不落点 |
| 右键 / 中键 | 平移 |
| 滚轮 | 缩放 |
| 铺轨 | 单击逐点；黄圈吸附；Z 撤销；Esc 结束 |
| 设站 | 靠近节点点击 |
| 工法 | 高架 / 桥梁 / 山隧 / 盾构 / 明挖 |
| 存档 | localStorage |
