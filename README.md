# 架空城市地铁建设沙盒（体验强化版）

在浏览器中运行的 3D 地铁自由建造沙盒。无胜负条件，可自由规划线路、设站、选择工法，并观察简化客流与城市发展。

## 如何运行

本项目为纯静态页面（Three.js 通过 CDN 加载），**无需 npm**。

在仓库根目录启动静态服务：

```bash
python3 -m http.server 8080
```

然后在浏览器打开：

- http://127.0.0.1:8080/
- 或 http://localhost:8080/

> 必须通过本地 HTTP 服务打开（不要直接双击用 `file://`），否则 ES Module / import map 可能无法加载。

若本机已有进程占用 8080，可换端口，例如：

```bash
python3 -m http.server 5173
```

## 新手感速览（本轮改进）

### 1. 铺轨更顺手
- **单击落点、拖拽不落点**，减少和视角操作打架
- **黄色吸附圈** + 更大吸附半径；可选网格对齐
- **幽灵预览管**（合法绿/线路色，阻断红）实时显示代价条
- **铺轨时自动俯视**（可关）；铺轨模式下降低旋转灵敏度
- **Z / Ctrl+Z /「撤销上点」** 撤销当前折线最后一点
- 快捷键 **1–4** 切换工具；Esc 结束折线

### 2. 视觉再抛光
- 轨道：Standard + 发光外管 + 工法细条
- 站点：站台圆盘 + 雨棚柱 + 顶盖，更易辨认
- 河面高光带微闪、建筑窗发光、市中心暖光、ACES 色调
- HUD 对比度加强（面板描边、数字加粗、危险 Toast 红色）

### 3. 客流体感
- 线段上有 **行驶中的小列车**（负载越高越多，拥堵时变慢）
- 站点上方 **+客运数字**，繁忙站点地面脉冲光环
- 路段按拥堵 **绿→黄→橙→红**，过载时外管闪烁
- 首次进入「偏满 / 拥挤」会 **Toast 提示**（可提高发车频率）
- 右侧 **客运趋势** 迷你折线图；小地图站点大小随客流变化

## 操作概要

| 操作 | 说明 |
|------|------|
| 右键拖拽 | 旋转视角 |
| 左键拖拽 | 平移（选择工具下）；铺轨时拖拽不落点 |
| 滚轮 | 缩放 |
| 新建线路 | 左侧面板 → 选颜色 → 铺轨 |
| 铺轨 | 单击逐点；Z 撤销；Esc 结束 |
| 设站 | 靠近已有节点点击 |
| 工法 | 高架 / 桥梁 / 山隧 / 盾构 / 明挖 |
| 发车频率 | 右侧线路列表：低 / 中 / 高 |
| 存档 / 读档 | 顶栏按钮（浏览器 localStorage） |

跨河请用**桥梁**（或盾构），穿山请用**山隧**；错误工法会提高难度点数与建造耗时，极端情况会阻止建造。
