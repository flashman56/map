# 架空城市地铁建设沙盒（MVP 原型）

在浏览器中运行的 3D 地铁自由建造沙盒。无胜负条件，可自由规划线路、设站、选择工法，并观察简化客流与城市发展。

## 如何运行

本项目为纯静态页面（Three.js 通过 CDN 加载），**无需 npm**。

```bash
python3 -m http.server 8080
```

然后在浏览器打开：

- http://127.0.0.1:8080/
- 或 http://localhost:8080/

> 必须通过本地 HTTP 服务打开（不要直接双击用 `file://`），否则 ES Module / import map 可能无法加载。

若本机已有进程占用 8080，可换端口，例如：

```bash
python3 -m http.server 5173
```

## 操作概要

| 操作 | 说明 |
|------|------|
| 右键拖拽 | 旋转视角 |
| 左键拖拽 | 平移（选择工具下） |
| 滚轮 | 缩放 |
| 新建线路 | 左侧面板 → 选颜色 → 铺轨 |
| 铺轨 | 左键逐点落轨；Esc 结束当前折线 |
| 设站 | 靠近已有节点点击 |
| 工法 | 高架 / 桥梁 / 山隧 / 盾构 / 明挖 |
| 发车频率 | 右侧线路列表：低 / 中 / 高 |
| 存档 / 读档 | 顶栏按钮（浏览器 localStorage） |

跨河请用**桥梁**（或盾构），穿山请用**山隧**；错误工法会提高难度点数与建造耗时，极端情况会阻止建造。

```
.

├── css/style.css
├── js/
│   ├── main.js         # 场景、输入、主循环
│   ├── world.js        # 地形 / 地质 / 城区 / 需求格
│   ├── metro.js        # 线路、节点、站点、轨道渲染

│   └── save.js         # localStorage

└── README.md
```

## MVP 功能对照

- [x] 浏览器可打开的 3D 场景（轨道控制）
- [x] 地形：平原、山、河、软土/硬岩色块、城区建筑
- [x] 自由矢量节点铺轨（可选吸附）
- [x] 多线路、颜色、设站
- [x] 五种工法 + 地形约束（阻断或提高代价）
- [x] 建造耗时条 + 难度点数预览
- [x] 简化客流：吸引、换乘阻抗、拥堵着色
- [x] 发车频率影响运力
- [x] 中文 HUD / 图例 / 迷你 2D 线路图
- [x] 城市发展（覆盖区需求缓慢上升）
- [x] localStorage 存读档

## 已知限制

- 客流为高度简化模型，非真实 OD / 时刻表
- 隧道在视觉上略埋入地面，未做完整地下剖切
- 无车辆行驶动画、无拆迁玩法
- CDN 需能访问 `cdn.jsdelivr.net`（three@0.160.0）
- 移动端未专门适配

## 技术

- Three.js r160（ES Module CDN + import map）
- 无构建步骤、无打包器
